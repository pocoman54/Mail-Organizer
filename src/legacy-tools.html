What do SUPPORTED, PARTIAL, and UNSUPPORTED mean?

SUPPORTED — Mail Organizer understands every condition and action needed to convert this Thunderbird filter.

PARTIAL — Mail Organizer understands part of the filter, but one or more items cannot yet be safely converted. The exact reason is shown in the Conversion column. The Thunderbird filter itself is not necessarily bad.

UNSUPPORTED — Mail Organizer cannot safely create a useful equivalent of this filter yet. It will not be selected by Select Supported.

Imported filters are disabled by default. Thunderbird's original filters are never modified.
